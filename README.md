# Healthy Balance Life — Dark Editorial Carousel Studio

Template pembuat carousel Instagram edukasi dengan nuansa gelap minimalis dan aksen turquoise. Tidak menggunakan foto wajah, manusia, hewan, atau karakter.

## File proyek

- `index.html` — halaman editor dan pratinjau 5 slide.
- `style.css` — sistem desain dark editorial.
- `app.js` — contoh materi, editor slide, navigasi, dan ekspor PNG.

## Cara menggunakan

1. Buka website melalui GitHub Pages, atau buka `index.html` di browser.
2. Edit judul utama dan subjudul untuk cover.
3. Edit judul, isi penjelasan, dan kalimat sorotan pada slide 2–5.
4. Pilih slide melalui tombol navigasi atau thumbnail.
5. Klik **Unduh 5 slide PNG**.

Ekspor PNG membutuhkan koneksi internet karena library `html-to-image` dimuat melalui CDN.

## Format dan gaya

- Ukuran ekspor: 1080 × 1350 px.
- Rasio: 4:5 (Instagram portrait).
- Background: charcoal / near-black dengan grain halus dan dekorasi abstrak.
- Warna teks: putih keabu-abuan.
- Aksen: turquoise `#43d6d8`.
- Tipografi: sans-serif editorial tebal.
- Tidak ada gambar wajah, manusia, hewan, atau ilustrasi karakter.
- Audiens utama: perempuan Indonesia usia 35+.
- Brand: Healthy Balance Life · Coach Kharina.

## Struktur konten

- Slide 1: judul utama yang kuat dan subjudul singkat.
- Slide 2–5: penjelasan edukatif bertahap, masing-masing dengan satu kalimat sorotan.

Contoh materi perimenopause di dalam editor hanya contoh awal. Periksa akurasi materi kesehatan dan sesuaikan dengan sumber tepercaya sebelum memublikasikan konten.
